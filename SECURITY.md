# Security Policy

## Supported Versions

This repository is the Airtable version of Bordful. Version 0.1.x is its final release line and receives security fixes only. No new features will be added.

| Version | Supported                        |
| ------- | -------------------------------- |
| 0.1.x (final legacy release, Airtable) | :white_check_mark: Security fixes only |
| < 0.1.61 | :x: Update to the latest 0.1.x |

Bordful 1.0, built on Payload, is in development and will replace this version.

## Reporting a Vulnerability

If you discover a security vulnerability, please follow these steps:

1. **Do Not** open a public issue
2. Email security details to support@bordful.com
3. Include:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested fix (if any)

We will:
- Acknowledge receipt within 48 hours
- Provide an estimated timeline for a fix
- Keep you updated on the progress

Thank you for helping keep Bordful secure!
